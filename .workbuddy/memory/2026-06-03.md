## OpenResty Windows x64 构建

- **目标**: 从 macOS 交叉编译 OpenResty 1.31.1.1 到 Windows x64
- **结论**: 直接从 macOS 交叉编译不可行（nginx/LuaJIT 构建系统深度绑定 MSYS2/MINGW64 环境）
- **最终方案**: GitHub Actions workflow，利用 Windows runner + MSYS2 原生构建

### 已完成
1. LLVM-MinGW 交叉编译器已安装 (`~/.workbuddy/binaries/llvm-mingw/`)
2. 创建了 `util/build-win64-cross.sh` 交叉编译脚本（保留备用）
3. 创建 `.github/workflows/build-win64.yml` 并推送到用户 fork `LiJie2324/openresty`
4. 创建了 Python 版 wget wrapper (`/tmp/wget-wrapper`) 解决本地 LibreSSL SSL 问题
5. **修复 build-win32.sh 的 GitHub Actions 构建失败**：
   - `wget` 在 MSYS2 里下载大文件不完整 → 改用 `curl -fL --retry 5 -C -`
   - `zlib.net` URL 不稳定 → 改用 `https://github.com/madler/zlib/releases/download/v1.3.2/`
   - `openssl-3.5.6` 版本不存在 → 修正为 `openssl-3.5.5`
   - 新增下载完整性校验（`gzip -t` 验证 tar.gz）
   - 新增 `openssl-3.5.6-sess_set_get_cb_yield.patch`（从 3.5.5 patch 复制）
